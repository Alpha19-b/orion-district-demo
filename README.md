# Orion District — démonstration

Application de démonstration du complexe sportif et de la boutique Orion District, Sonfonia T7.

Ouvrir le lien GitHub Pages dans Safari sur iPhone, Chrome sur Android ou un navigateur sur ordinateur. Aucun téléchargement de fichier HTML n’est nécessaire.

## Parcours à essayer

1. Choisir « Espace client » et découvrir le club et la boutique.
2. Ouvrir la connexion et choisir un compte de démonstration.
3. Tester le pass QR, les programmes, les cours, le coaching et les avantages boutique.
4. Revenir au choix des espaces pour explorer la gestion avec les rôles admin, manager, réception et vendeur.

Les connexions, paiements et entrées sont simulés. Le QR ne commande aucun tourniquet réel. Chaque navigateur conserve ses propres essais : les données ne sont pas synchronisées entre les associés. Utiliser exclusivement des informations fictives.

## Publication GitHub Pages

Déposer `index.html`, `.nojekyll` et ce fichier à la racine du dépôt.
Dans **Settings → Pages → Build and deployment**, choisir **Deploy from a branch**, puis **main / (root)** et **Save**.
Partager l’adresse affichée par GitHub Pages après publication, pas le lien vers le fichier dans le dépôt.

L’image et le code de la démonstration sont intégrés à `index.html`. Les polices distantes sont facultatives ; une police de remplacement s’affiche si elles sont indisponibles.
